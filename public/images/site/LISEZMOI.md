# Photos du site

Déposez vos photos dans ce dossier **avec exactement ces noms** : elles s'affichent automatiquement
au prochain `npm run build` (ou déploiement). Tant qu'une photo manque, un dégradé ou l'initiale s'affiche.

| Fichier | Où | Format conseillé |
|---|---|---|
| `voiture.jpg` | Accueil, grande tuile « Une voiture récente » (actuellement : la photo de l'Audi A1) | Paysage 4:3, 1600 × 1200 px minimum |
| `salle-code.jpg` | Accueil, tuile « Le code en salle » (actuellement : la photo de la salle) | Paysage 4:3, 1200 × 900 px |
| `equipe-soraya.jpg` | Accueil, cercle de l'équipe | Carré, 800 × 800 px, visage centré |
| `equipe-philippe.jpg` | idem | idem |
| `equipe-david.jpg` | idem | idem |
| `equipe-bernadette.jpg` | idem | idem |
| `equipe-toufik.jpg` | idem | idem |

Conseils : photos nettes et lumineuses, JPG de moins de 500 Ko (compressez sur squoosh.app),
et accord écrit des personnes photographiées.
